## 4. 协作硬约束

1. **三层单向依赖**：`web → server → backend`；`backend` 禁止 include 任何 Drogon 头文件；`server` 只做参数解析、鉴权、调用与响应封装，禁止实现业务算法。
2. **中层不互调**：`tree_builder`、`traversal`、`search`、`stats`、`operations` 之间不得互相 include；需复用则下沉到 `tree_node`。
3. **前端不碰后端**：前端只能通过 REST API 与后端通信，禁止绕过 `src/api/` 封装直接调用 axios/fetch；权限判断以服务端返回为准，前端隐藏菜单不作为安全边界。
4. **接口冻结**：`TreeNode` 等核心结构字段、模块函数签名、HTTP 接口字段不得私自变更，确需变更走《技术栈定版与开发规范》第 7 章流程。
5. **错误码统一**：0 成功；-1 通用失败；-2 路径不存在；-3 无权限访问/路径越界；-4 账号密码错；-5 锁定；-6 禁用；-7 重名；-8 非法移动；-9 权限不足；-10 I/O 失败；-11 token 失效/未登录；-12 参数非法。
6. **联调契约**：前后端以《模块接口对接文档 v2.0》第 4 章 HTTP API 明细为唯一依据；接口未就绪时前端用 mock 数据并行开发，字段以文档为准。
7. **AI 协作**：AI 生成代码必须人工审查并加 `// AI生成，已手动审查修改` 注释（前端同理）。
